# Jett downloads

Public installers and release notes for Jett. Application source is maintained in a separate private repository.

## First test beta

[Download Jett 0.1.1 beta for Mac with Apple Silicon](https://github.com/jittergtz/jett-downloads/releases/tag/v0.1.1-beta.1).

This experimental prerelease is for installation and login testing with disposable test mailboxes. It is not a stable release. Intel Mac and Windows installers are not included yet.

The macOS app is ad-hoc signed and **not notarized**. Local mailbox metadata and cached content are **not encrypted at rest** in this build. Online mail uses the currently deployed Jett service; publishing an installer does not update that service. Full offline mail and automatic app updates are not promised by this release.

Download the DMG and follow the release's installation instructions. Each release includes `SHA256SUMS` and `release.json` for file verification.
